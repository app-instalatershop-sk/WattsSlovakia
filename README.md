# WattsSlovakia – prezentačný web značky Microflex

Prezentačná stránka produktov značky **Microflex** pre slovenský trh.
Európsky katalóg značky prenášame do slovenčiny, aby sme s produktmi a katalógom
zaujali a obsadili prvú priečku vo vyhľadávaní na Slovensku. Stránka sama nepredáva –
kto má záujem, kúpi na [instalatershop.sk](https://www.instalatershop.sk). Súčasťou bude aj B2B časť.

## Stav

Fáza prípravy podkladov: grafika, zoznam produktov, katalógy a informácie, ktoré
poslúžia ako plán stavby stránky. Technické riešenie (stack, hosting) sa rozhodne až potom.

## Repozitáre

Kód sa verziuje na dvoch GitHuboch naraz: `Jurajj8/WattsSlovakia` a firemný
`app-instalatershop-sk/WattsSlovakia`.
